# Sources and fact check: #002 Longitude

I checked these claims with web searches in September 2026. Publisher pages were mostly blocked from this environment, so claims marked **(summary)** rest on search-result summaries.

## What's illustrative, and labelled on screen

- The fleet track near Scilly ("fleet track schematic").
- The voyage routes via Madeira and Cook's loop ("route illustrative").
- The gridiron's expansion, which is exaggerated ("expansion exaggerated").
- The verge escapement, which is stylised ("stylised verge escapement").
- The Longitude Act title page, which is set in modern type in the style of the original. The wording follows the Act's title.
- "One watch might be luck" is shown without quotation marks because it paraphrases the Board's position.
